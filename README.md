# mondayDB Agentic Strategy

Daily strategy contracts that move mondayDB from a WorkOS engine toward a deterministic Agentic Database.

This increment ships the **Extended Working-Set Purpose Gate Plane**: envelope-scoped gates decide whether a citation placed into a working set whose clock was re-armed may be read or tool-read. A re-armed clock is a watermark. It is not `TRUSTED_ENROLLED`, not a fact restore, and not a body read.

```bash
npm install
npm run validate
```
