# mondayDB Agentic Evolution

Strategic product and engineering artifacts for evolving mondayDB from a high-performance WorkOS engine into an agent-ready database while preserving deterministic behavior, tenant isolation, and predictable scale.

## Current artifacts

- [Agentic Schema Contract Plane](docs/agentic-schema-contract-plane.md) - deterministic, tenant-scoped contracts that describe board fields, procedures, semantic metadata, guardrails, GraphQL APIs, audit trails, and safe planner access paths for autonomous agents.
