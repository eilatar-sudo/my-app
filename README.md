# mondayDB Agentic Database Strategy

Strategic product and engineering artifacts for evolving mondayDB from a high-performance WorkOS engine into a deterministic, enterprise-grade agentic database.

## Current proposal

- [Multi-Agent Coordination Plane](docs/agentic-multi-agent-coordination-plane.md) — tenant-scoped work claims, optimistic revision fences, duplicate-action receipts, transactional tool outboxes, Open API GraphQL contracts, bounded procedural retrieval, and explicit guardrails for 1M+ row boards.
