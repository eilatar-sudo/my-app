# mondayDB Agentic Database Strategy

This repository contains strategic product and engineering artifacts for evolving mondayDB into an enterprise-grade agentic database.

## Current artifact

- [Agentic Consent and Delegation Plane](docs/agentic-consent-delegation-plane.md): deterministic tenant-scoped consent, delegation evaluation, GraphQL API shape, TypeScript and SQL schemas, semantic retrieval compatibility, auditability, and guardrails for autonomous agents.
