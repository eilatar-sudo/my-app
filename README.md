# mondayDB Agentic Database Strategy

This repository contains strategic product and engineering proposals for
evolving mondayDB into a deterministic, enterprise-grade agentic database.

## Current proposal

- [Agentic Emergency Containment Plane](docs/agentic-emergency-containment-plane.md) —
  tenant-scoped stop, drain, quarantine, reconciliation, and release controls
  for autonomous workloads.
