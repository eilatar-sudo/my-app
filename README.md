# mondayDB Agentic Database Vision

This repository captures architecture slices for evolving mondayDB from a
high-performance WorkOS engine into an enterprise-grade agentic database.

## Architecture artifacts

- [Agentic Readiness Manifest Plane](docs/agentic-readiness-manifest-plane.md):
  deterministic, tenant-scoped readiness manifests that expose procedural
  memory, semantic retrieval coverage, Open API contracts, audit hashes, and
  workload guardrails before an autonomous agent acts.
