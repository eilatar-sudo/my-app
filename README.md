# mondayDB Agentic Strategy

Daily strategy contracts that move mondayDB from a WorkOS engine toward a deterministic Agentic Database.

This increment ships the **SLA Extension Certificate Plane**: dual-control certificates re-arm a successor clock on a sealed halt-aware working set. Extension never restores a disputed fact, never rewrites a terminal as `TRUSTED_ENROLLED`, and never opens another nested expiry-containment-review-resolution plane.

```bash
npm install
npm run validate
```
