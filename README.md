# mondayDB Agentic Strategy

Daily strategy contracts that move mondayDB from a WorkOS engine toward a deterministic Agentic Database.

This increment ships the **Terminal Working-Set Compilation Plane**: sealed `REQUIRE_HUMAN` and `PERMANENT_QUARANTINE` certificates compile into halt-aware working-set packets. Compilation never rewrites a terminal as `TRUSTED_ENROLLED`, never restores a quarantined body, and never opens another nested expiry-containment-review-resolution plane.

```bash
npm install
npm run validate
```
