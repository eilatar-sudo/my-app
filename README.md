# mondayDB Agentic Evolution

This repository contains strategic product and engineering artifacts for
evolving mondayDB from a high-performance WorkOS engine into an agent-ready,
enterprise-grade database layer.

## Artifacts

- [Agentic Evaluation and Regression Plane](docs/agentic-evaluation-regression-plane.md)
  - Deterministic tenant-scoped evaluation suites for retrieval, plan
    verification, tool execution, transaction intents, and memory compaction.
