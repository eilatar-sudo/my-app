# mondayDB Agentic Evolution

This repository contains strategic product and engineering artifacts for
evolving mondayDB from a high-performance WorkOS engine into an agent-ready,
enterprise-grade database layer.

## Artifacts

- [Agentic Entity Graph Plane](docs/agentic-entity-graph-plane.md)
  - Deterministic tenant-scoped entity and relationship graph for agent
    perception, procedural memory, semantic entry-point retrieval, audit replay,
    and recursive-query guardrails.
